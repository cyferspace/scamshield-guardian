# ScamShield: Senior & Family Digital Fraud Guardian

## The Problem
Seniors and vulnerable family members frequently fall victim to urgent digital fraud, phishing SMS, and utility scam threats.

## The Solution
ScamShield is a highly accessible web scanner that flags deceptive messaging patterns. It assigns threat levels and provides plain-English next steps to prevent financial loss and data theft.

## Features
* **Senior-Friendly UI:** High contrast, large text, and distinct color-coded alerts (Red, Yellow, Green).
* **Instant Analysis:** Scans for phishing keywords, urgency tactics, and impersonation.
* **Actionable Advice:** Tells the user exactly what to do (e.g., "Do not click. Delete the message.").

## Tech Stack
* React
* Vite
* Tailwind CSS
